# Публикация «Твой Диетолог» в RuStore

Бесплатно, без $25 как в Google Play. Регистрация: https://console.rustore.ru

## 1. Регистрация разработчика

1. Зайди на https://console.rustore.ru
2. Войди через VK ID или другой доступный способ
3. Заполни профиль разработчика (физлицо или ИП/ООО — по документам RuStore)
4. Дождись верификации аккаунта

## 2. Создание приложения

1. **Приложения** → **Добавить приложение**
2. Название: `Твой Диетолог`
3. Тип: **Универсальное** (телефон/планшет)
4. Package name (уже в APK): `com.tvoydietolog.app`

## 3. APK и иконка для RuStore

### Иконка (1:1, 32–512 px, до 1 МБ)

Готовые файлы в репозитории:

```
mobile/store/rustore_icon_512.png  ← загружай эту в консоль (512×512, ~250 KB)
mobile/store/rustore_icon_256.png
mobile/store/rustore_icon_128.png
```

Перегенерировать из аватара бота:

```bash
python3 mobile/scripts/generate_launcher_icons.py
```

### APK для загрузки

Бери готовый релиз с GitHub:

https://github.com/GermannM3/dieta/releases/latest

Файл: **app-release.apk** (подписан release-ключом, один и тот же для всех обновлений).

Требования RuStore:
- APK подписан цифровым сертификатом ✓
- `versionCode` каждой новой версии больше предыдущей ✓
- Подпись совпадает с прошлыми версиями ✓
- Размер до 5 ГБ ✓

### Отпечаток подписи (SHA-256)

Если консоль попросит fingerprint, на машине с keystore:

```bash
keytool -list -v -keystore upload-keystore.jks -alias upload
```

Пароль keystore хранится в GitHub Secrets CI (`ANDROID_KEYSTORE_PASSWORD`).

## 5. Безопасность данных (декларация разрешений)

В приложении запрашивается только:
- **INTERNET** — работа с API и ИИ
- **ACCESS_NETWORK_STATE** — проверка сети

Разрешения `REQUEST_INSTALL_PACKAGES`, `READ/WRITE_EXTERNAL_STORAGE` **удалены** — RuStore их не пропускает. Обновления только через RuStore SDK.

## 6. Отправка на модерацию

1. **Загрузить версию** → выбери APK
2. Заполни «Что нового?»
3. Проверь декларацию данных
4. **Отправить на модерацию**

Модерация обычно 1–3 рабочих дня.

## 7. Обновления после публикации

1. Подними версию в `mobile/pubspec.yaml` (например `1.3.2+6`)
2. Создай тег: `git tag android-v1.3.2 && git push origin android-v1.3.2`
3. Дождись сборки на GitHub Actions
4. В RuStore Консоль → **Новая версия** → загрузи новый APK

В приложении пользователи с RuStore получат обновление через **RuStore SDK** (Профиль → Проверить обновления).

## Частые проблемы

**«Подпись не совпадает»** — загружаешь APK, подписанный другим ключом. Всегда используй релизы с GitHub Actions (keystore в кэше CI).

**Модерация отклонила REQUEST_INSTALL_PACKAGES** — убери sideload-обновления из APK (версия 1.3.3+). Загрузи новую сборку без этого разрешения.

**Обновления RuStore SDK не работают** — нужны 2 версии в консоли (старая и новая), RuStore установлен на телефоне, пользователь авторизован в RuStore.
